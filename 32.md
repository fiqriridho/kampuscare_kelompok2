## 2. ACUAN MATERI MODUL 3

Gunakan materi berikut sebagai pedoman utama.

### A. Synchronous vs Asynchronous

- Synchronous: tugas dijalankan satu per satu secara berurutan. Tugas berikutnya menunggu tugas sebelumnya selesai.
- Asynchronous: program dapat menjalankan tugas lain tanpa harus menunggu operasi asynchronous selesai.

### B. Async Function

- Fungsi yang dideklarasikan menggunakan kata kunci `async`.
- Async function secara otomatis mengembalikan sebuah Promise.
- Digunakan untuk menjalankan proses asynchronous.

Contoh:

```typescript
async function getData() {
  return "Data berhasil diambil";
}
```

### C. Promise dan Await

- Promise merupakan object yang merepresentasikan hasil operasi yang masih dalam proses.
- `await` digunakan untuk menunggu Promise selesai sebelum melanjutkan baris kode berikutnya.
- `resolve()` digunakan ketika operasi berhasil.
- `reject()` digunakan ketika operasi gagal.

Contoh:

```typescript
async function getData() {
  const result = await someAsyncOperation();
  return result;
}
```

### D. Pre-built Async Function

Fungsi asynchronous yang sudah disediakan oleh JavaScript atau library yang digunakan.

Contoh:
- `fetch()` untuk melakukan HTTP request dan mengambil data dari API.
- Fungsi asynchronous bawaan atau library lain yang memang digunakan dalam project.

### E. Custom Async Function

Fungsi asynchronous yang dibuat sendiri oleh programmer menggunakan kata kunci `async`.

Fungsi ini dapat:
- Memanggil fungsi asynchronous lainnya.
- Menggunakan `await` untuk menunggu hasil operasi.
- Mengolah hasil operasi asynchronous.
- Mengatur alur proses asynchronous dalam aplikasi.

Contoh:

```typescript
async function getUsers() {
  const response = await fetch("API_ENDPOINT");
  const data = await response.json();

  return data;
}
```

Contoh di atas menunjukkan hubungan antara custom async function (`getUsers`) dan pre-built async function (`fetch`).
